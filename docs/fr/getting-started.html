Des entrées approuvées du dossier à un premier tour d’exécution

Fournissez un modèle.
Commencez par un dossier métier.

Commencez par une inspection sans identifiants d’authentification. Utilisez ensuite les textes fictifs d’un appel d’offres et des capacités produit pour une demande de recherche en lecture seule. Il s’agit d’un contrôle d’intégration limité, première étape vers un atelier de réponse aux appels d’offres dans votre application, et non d’un workflow d’assistant de programmation.

Le package n’est pas sur NuGet.org. Le package HveSquad.AgentFramework en version 0.1.0-preview.1 est une préversion non publiée. Utilisez la méthode par référence de projet ci-dessous ou créez un package pour un flux local. Aucun service MCP distinct n’est nécessaire. Les mainteneurs suivent les instructions de publication du package avant toute annonce d’installation depuis un flux public.

La copie de travail des sources de l’intégration et le répertoire du dossier métier sont deux choses distinctes : Git/APM acquièrent les artefacts publiés ; le répertoire du dossier conserve le travail de l’application.

01. Inspecter une version publiée

Clonez le dépôt de l’intégration si vous ne l’avez pas encore, puis compilez-le. L’inspection n’effectue aucun appel payant à un modèle, mais les commandes relatives aux versions publiées nécessitent un accès réseau et APM.

PowerShell · Cloner et vérifier les outils
New-Item -ItemType Directory -Force C:\Solutions | Out-Null
Set-Location C:\Solutions
git clone https://github.com/Peter-N91/hve-squad-maf.git
Set-Location C:\Solutions\hve-squad-maf
dotnet --version
git --version
apm --version
dotnet build HveSquad.AgentFramework.slnx

dotnet run --project samples\HveSquad.AgentFramework.Sample -- --release v0.16.2
dotnet run --project samples\HveSquad.AgentFramework.Sample -- --latest

Vous devez obtenir le tag de version, le commit, le nombre d’artefacts, les profils et packs disponibles, ainsi qu’une description du workflow par étapes. Pour v0.16.2, le commit testé est a941195c36dfb6181453f51ec4638b085ca3b3ad. Les avertissements concernant les délégués externes à activer explicitement ne signifient pas que ces capacités sont installées.

Sans argument, l’inspecteur remonte l’arborescence à la recherche d’artefacts de projet installés. Les arguments positionnels de répertoire permettent d’inspecter des racines d’artefacts explicites. Aucune de ces deux méthodes ne correspond à l’acquisition de version par défaut du runtime en exécution réelle.

02. Exécuter l’exemple console existant

Définissez OPENAI_API_KEY et OPENAI_MODEL dans l’environnement du processus à l’aide de votre gestionnaire de secrets ou d’une configuration locale sécurisée. Ne placez pas d’identifiants d’authentification dans les sources, l’historique des commandes ou le JSON d’exécution. L’exemple exige les deux variables.

OPENAI_ENDPOINT est facultatif et doit être un URI HTTP ou HTTPS absolu. Utilisez HTTPS pour les fournisseurs distants ; HTTP en clair ne convient qu’à un point de terminaison local explicitement approuvé. Les fournisseurs compatibles OpenAI, y compris un point de terminaison Azure OpenAI v1 correctement configuré, doivent prendre en charge le modèle sélectionné et les appels d’outils.

PowerShell · Entrées textuelles fictives et demande de recherche en exécution réelle
Set-Location C:\Solutions\hve-squad-maf
New-Item -ItemType Directory -Force C:\app-data\bid-cases\demo\inputs | Out-Null
Set-Content -LiteralPath C:\app-data\bid-cases\demo\inputs\rfp.txt -Encoding utf8 `
  -Value "RFP-01 (fictional): Which input formats does the knowledge-search product support?"
Set-Content -LiteralPath C:\app-data\bid-cases\demo\inputs\approved-capabilities.txt -Encoding utf8 `
  -Value "CAP-01 (fictional approved evidence): Knowledge search accepts plain text. No other formats are evidenced."

dotnet run --project samples\HveSquad.AgentFramework.Sample -- `
  --run "Research the question in inputs\rfp.txt using inputs\approved-capabilities.txt. Cite source identifiers and report gaps. Stop after research; do not change inputs or send anything externally." `
  --project C:\app-data\bid-cases\demo `
  --version v0.16.2 `
  --profile full

Ces fichiers de test ne contiennent aucune donnée réelle de client ou de produit. Utilisez un nouveau répertoire de démonstration ; les commandes remplacent les deux fichiers nommés. Examinez les propositions complètes d’initialisation et de routage, y compris le périmètre limité à la recherche. Ne saisissez yes que si vous approuvez la proposition effectivement affichée. Répondez aux éventuelles questions ou arrêtez avec Ctrl+C. Une exécution ciblée sur la recherche écrit des éléments probants de recherche, et non une réponse finalisée à l’appel d’offres.

Ce que l’exemple peut réellement faire : lire les fichiers contenus dans le répertoire du dossier et écrire des artefacts méthodologiques au périmètre délimité. Il enregistre également un outil write_project_file limité à ce répertoire pour le rôle developer, après approbation explicite ; cette démonstration facultative d’écriture de code source n’est nécessaire ni pour cette demande ni pour la finalité métier de l’application. Il ne dispose d’aucun exécuteur de shell, de compilation, de tests, de recherche web ou de déploiement. Le raccordement à la bibliothèque ci-dessous n’enregistre aucun outil de l’hôte.

Alternative par fichier de configuration

Enregistrez ce contenu dans run.json dans le dépôt de l’intégration. Il s’agit des champs de la CLI de l’exemple, et non du schéma complet de configuration du runtime.

JSON · run.json
{
  "request": "Research the question in inputs\\rfp.txt using inputs\\approved-capabilities.txt. Cite source identifiers and report gaps. Stop after research; do not change inputs or send anything externally.",
  "project": "C:\\app-data\\bid-cases\\demo",
  "version": "v0.16.2",
  "profile": "full"
}
PowerShell · Exécuter la configuration
dotnet run --project samples\HveSquad.AgentFramework.Sample -- --config run.json

Les options de la CLI sont --run, --project, --version et --profile. --config accepte un seul fichier et ne se combine pas avec ces options. Les membres JSON inconnus et les options non valides ou répétées sont rejetés. Une livraison, une recherche, une planification ou une revue réussie renvoie le code de sortie 0 ; les autres résultats renvoient 1, les arguments non valides renvoient 2 et l’annulation renvoie 130.

03. Ajouter une référence de projet

C’est la méthode d’intégration la plus simple avant publication. Elle compile la bibliothèque directement depuis votre copie de travail. L’adaptateur OpenAI ci-dessous n’est nécessaire que pour l’exemple autonome de fournisseur, pas pour les appelants qui disposent déjà d’un IChatClient.

PowerShell · Créer une application consommatrice
dotnet new console --framework net10.0 --output C:\projects\SquadHost
dotnet add C:\projects\SquadHost\SquadHost.csproj reference `
  C:\Solutions\hve-squad-maf\src\HveSquad.AgentFramework\HveSquad.AgentFramework.csproj
dotnet add C:\projects\SquadHost\SquadHost.csproj package `
  Microsoft.Extensions.AI.OpenAI --version 10.8.3

04. Raccorder votre IChatClient

Ajoutez le contenu suivant dans SquadEntry.cs dans l’application consommatrice. L’application fournit le client et le répertoire autorisé du dossier préparé ci-dessus ; les callbacks console permettent d’approuver explicitement les propositions et de répondre aux questions. Cette première demande recherche uniquement les éléments probants relatifs aux capacités. Pour le traitement complet de rédaction géré par l’application, incluant la sélection typée de la sortie et les callbacks d’interface utilisateur, utilisez BidDraftService.DraftAsync.

C# · SquadEntry.cs
using System.Text.Json;
using HveSquad.AgentFramework.Runtime;
using Microsoft.Extensions.AI;

internal static class SquadEntry
{
    public static async Task<SquadRunResult> ResearchAsync(
        IChatClient chatClient,
        string caseDirectory,
        CancellationToken cancellationToken = default)
    {
        var options = new SquadRuntimeOptions
        {
            ProjectPath = caseDirectory,
            Profile = "full",
            Version = "v0.16.2",
            InputPaths = [@"inputs\rfp.txt", @"inputs\approved-capabilities.txt"],
            Tools = [],
            ApprovalChannel = "in-chat",
            ApproveAsync = async (proposal, token) =>
            {
                Console.WriteLine(JsonSerializer.Serialize(proposal));
                Console.Write("Approve this exact proposal? Type yes: ");
                return string.Equals(
                    await Console.In.ReadLineAsync(token),
                    "yes", StringComparison.OrdinalIgnoreCase);
            },
            AskAsync = async (question, token) =>
            {
                Console.WriteLine($"{question.Role}: {question.Question}");
                return await Console.In.ReadLineAsync(token);
            }
        };

        using var squad = await SquadRuntime.CreateAsync(
            chatClient, options, cancellationToken: cancellationToken);
        return await squad.RunAsync(
            "Research the supplied RFP question using only approved capability evidence. " +
            "Cite source identifiers and report gaps. Stop after research; " +
            "do not change inputs or send anything externally.",
            cancellationToken);
    }
}

Si vous disposez déjà d’un client configuré, appelez SquadEntry.ResearchAsync(chatClient, caseDirectory, cancellationToken) depuis votre application. Le runtime ne libère pas ce client. InputPaths n’est pas une liste d’autorisation de lecture : les lectures natives peuvent accéder à d’autres fichiers contenus dans le répertoire ; n’y placez donc que les documents autorisés pour le dossier. Tools = [] supprime les capacités personnalisées de l’hôte, mais pas la lecture native, l’écriture d’artefacts ni la persistance de l’état.

La liste de rôles full comprend également les rôles technical-writer et de validation des entrées nécessaires à l’exemple de livraison présenté plus loin. Une recherche seule ne déclenche pas la validation des entrées. Une demande de livraison ou de planification avec ces entrées la déclenche, et le PRD Quality Reviewer publié peut ne pas convenir à des documents d’appel d’offres quelconques ; gérez un blocage explicite plutôt que de promettre une validation générique des documents.

Raccordement autonome à un fournisseur

Pour le nouveau projet console ci-dessus, remplacez Program.cs par cet exemple complet. Il lit un environnement déjà configuré et ne contient aucun identifiant d’authentification en dur.

C# · Program.cs
using System.ClientModel;
using Microsoft.Extensions.AI;
using OpenAI;

var key = Environment.GetEnvironmentVariable("OPENAI_API_KEY")
    ?? throw new InvalidOperationException("Provision OPENAI_API_KEY securely.");
var model = Environment.GetEnvironmentVariable("OPENAI_MODEL")
    ?? throw new InvalidOperationException("Set OPENAI_MODEL for your provider.");
var clientOptions = new OpenAIClientOptions();
var endpoint = Environment.GetEnvironmentVariable("OPENAI_ENDPOINT");
if (!string.IsNullOrWhiteSpace(endpoint))
    clientOptions.Endpoint = new Uri(endpoint, UriKind.Absolute);

var provider = new OpenAIClient(new ApiKeyCredential(key), clientOptions);
using IChatClient chatClient = provider.GetChatClient(model).AsIChatClient();
using var cancellation = new CancellationTokenSource();
Console.CancelKeyPress += (_, e) =>
{
    e.Cancel = true;
    cancellation.Cancel();
};

try
{
    var result = await SquadEntry.ResearchAsync(
        chatClient, @"C:\app-data\bid-cases\demo", cancellation.Token);
    Console.WriteLine($"{result.Status}: {result.ResponseText}");
    Console.WriteLine($"Verified dispatches: {result.Evidence.Count}");
}
catch (OperationCanceledException)
{
    Console.WriteLine("Cancelled. No completion is claimed.");
}
PowerShell · Exécuter votre application
dotnet run --project C:\projects\SquadHost\SquadHost.csproj

ResearchCompleted signifie que la recherche est terminée, pas l’implémentation. Traitez ApprovalRequired, InputRequired et les éléments probants partiels comme des résultats à part entière. Les erreurs de configuration, d’acquisition, de validation de l’état et de verrouillage peuvent lever des exceptions avant qu’un résultat d’exécution n’existe. Consultez le contrat complet des résultats.

Alternative : utiliser un package local

Choisissez cette méthode à la place de la référence de projet. N’ajoutez pas les deux références à une même application consommatrice. Ces commandes créent un package à partir des sources actuelles et restaurent les dépendances depuis le flux local et NuGet.org pour les dépendances publiques. Créer un package ne revient pas à le publier ; consultez la procédure de publication destinée aux mainteneurs.

PowerShell · Compiler, créer le package et restaurer localement
Set-Location C:\Solutions\hve-squad-maf
dotnet build HveSquad.AgentFramework.slnx --configuration Release
dotnet pack src\HveSquad.AgentFramework --configuration Release --output artifacts

dotnet new console --framework net10.0 --output C:\projects\SquadPackageHost
dotnet add C:\projects\SquadPackageHost\SquadPackageHost.csproj package `
  HveSquad.AgentFramework --version 0.1.0-preview.1 --no-restore
dotnet add C:\projects\SquadPackageHost\SquadPackageHost.csproj package `
  Microsoft.Extensions.AI.OpenAI --version 10.8.3 --no-restore
dotnet restore C:\projects\SquadPackageHost\SquadPackageHost.csproj `
  --source C:\Solutions\hve-squad-maf\artifacts `
  --source https://api.nuget.org/v3/index.json

Ajoutez les mêmes fichiers SquadEntry.cs et Program.cs que ci-dessus, puis exécutez dotnet run --project C:\projects\SquadPackageHost --no-restore. Pour une utilisation régulière, ajoutez le flux local au NuGet.Config de l’application consommatrice ; conservez toute politique de mappage des sources de packages de votre organisation. Le package généré est artifacts\HveSquad.AgentFramework.0.1.0-preview.1.nupkg, et non un téléchargement publié.

Uniquement après publication

L’installation depuis un flux public ci-dessous n’est PAS disponible tant qu’un mainteneur n’a pas publié cette version. Elle montre la commande prévue pour les consommateurs du package, et non une installation publique fonctionnelle à ce jour.

PowerShell · Après publication par un mainteneur, dans votre projet d’application
dotnet add package HveSquad.AgentFramework --version 0.1.0-preview.1

Utiliser l’injection de dépendances dans un hôte existant

AddHveSquad renvoie la collection de services et enregistre une SquadRuntimeFactory avec une durée de vie transitoire. Il s’agit d’un modèle de fabrique asynchrone, et non d’un runtime construit de manière synchrone. L’acquisition a lieu dans CreateAsync.

JSON · Section de configuration de l’application
{
  "HveSquad": {
    "ProjectPath": "C:\\app-data\\bid-cases\\demo",
    "Profile": "full",
    "Version": "v0.16.2",
    "Mode": "interactive",
    "Packs": [],
    "InputPaths": ["inputs\\rfp.txt", "inputs\\approved-capabilities.txt"],
    "MaxDispatches": 32,
    "MaxModelCalls": 64,
    "RunTimeout": "00:30:00"
  }
}

Le code suivant se place au point de composition de votre hôte existant. services, configuration, chatClient et serviceProvider sont fournis par cette application. Les callbacks de l’hôte utilisent les mêmes signatures que dans l’exemple d’utilisation directe.

C# · Composition de l’hôte et gestion du cycle de vie du runtime
using HveSquad.AgentFramework.Hosting;
using Microsoft.Extensions.AI;
using Microsoft.Extensions.DependencyInjection;

services.AddSingleton<IChatClient>(chatClient);
services.AddHveSquad(
    configuration.GetSection("HveSquad"),
    configureHost: options =>
    {
        options.ApproveAsync = ApproveInYourApplicationAsync;
        options.AskAsync = AskInYourApplicationAsync;
    });

// Later, resolve from your application's built service provider.
var factory = serviceProvider.GetRequiredService<SquadRuntimeFactory>();
using var squad = await factory.CreateAsync(cancellationToken);
var result = await squad.RunAsync(request, cancellationToken);

Chaque appel à la fabrique crée un runtime dont le cycle de vie est géré indépendamment. Cette configuration décrit un dossier de démonstration, et non un répertoire multilocataire partagé par toutes les requêtes. L’application doit autoriser et sélectionner un répertoire persistant distinct pour chaque dossier métier, et sa file d’attente doit imposer une seule exécution active par dossier. Ne libérez pas un runtime tant que son exécution est active.

Enregistrez les outils, les filtres, la journalisation, la sélection du modèle et les callbacks dans le code, jamais dans le JSON. Pour une interface utilisateur hébergée, implémentez une véritable interaction humaine plutôt qu’une approbation inconditionnelle. Les callbacks attendent les réponses dans la limite de RunTimeout ; il n’existe ni suspension durable pour approbation ni reprise automatique d’un traitement en arrière-plan. L’application prend en charge l’ingestion des documents et les droits associés, le transport des approbations, l’état des traitements et la remise sécurisée des résultats. Consultez les limites de responsabilité de l’application.
