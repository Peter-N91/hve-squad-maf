Architecture / Federation & scope
Discuss the design ↗

Producer-first execution, unchanged inner authority

Named squads.
Preserved evidence.

The native controller initializes, promotes and expands in-repository federations, then runs actual dependency-ordered MAF members. Producer artifacts are enumerated, verified and handed to consumers read-only. Untargeted autopilot aggregates cost, attributed gates and one final human outcome. Authorized Watch events use one isolated event member and the same governed inner engine.

Completed work is not release permission. A registry is not a delivered outcome, and consolidated acceptance never authorizes deployment, push or merge. IndustryIQ still needs tenant/case authorization, privileged connectors and business-quality validation. The supported release remains pinned.

Detection and exact confirmation

SquadFederation.GetSnapshot() checks the federation registry first, otherwise the top-level roster, otherwise Init. A stray top-level roster alongside the registry is reported for explicit reconciliation. Creating the controller and reading metadata do not create native state or make model calls.

InitializeAsync(members) builds a fresh federation or additively expands an existing one. Every proposed member has a required unique lower-kebab-case name, an actual roster, a purpose and routes. The existing ApproveAsync receives a complete Federation payload with FederationInitialization, FederationPromotion or FederationExpansion. No files are written before that exact local confirmation.

A child agent is not a sub-squad.

NATIVE DISPATCH

Delegate within an owner's scope

A declared child shares its producing owner's scope, limits and effect authority. Its real dispatch is not another independent roster or case.

Creating more children cannot replace federation registration or human confirmation.

REGISTERED MEMBER

Run an independent native squad

CreateMemberRuntimeAsync(name, readOnlyInputs) opens the existing inner engine at .copilot-tracking/squad/members/<name>. Its native release/configuration, actual sessions, historical spend and mandatory gates remain local.

Member reads stay inside that root or exact host-approved files. Actual repository-wide docs/outputs paths receive durable member ownership before writing; another member cannot borrow them.

Producer-first execution and its boundaries

  1. Confirm the actual script

    GetRoutingProposal honors an explicit target and most-specific literal patterns. Disjoint ambiguity reaches a human. Typed Dependencies order actual registered producers before consumers; only explicitly independent outcomes may overlap. A missing owner offers confirmed expansion, a user artifact or a visible attributed Ready-With-Gaps assumption.

  2. Verify every input boundary

    The coordinator reads current roster roots, bounded-enumerates producer artifacts, verifies their native receipts and records exact raw hashes. State/history cannot substitute for an artifact. An unrun producer runs in the same turn; a stale/partial artifact repairs only its named stage. A second miss escalates rather than looping. Consumers cannot modify or enumerate another root; a requested producer edit returns to that producer.

  3. Keep one aggregate authority

    Untargeted host Mode = "autopilot" uses ordinary inner pipelines, one root tariff/calibration and complete inner/meta demand priced once. There is no root consumption ledger or fabricated native model charge. An aggregate ceiling uses sequential member barriers; ungated independent members may overlap. Unknown rates/spend and at-ceiling states cannot be approved. Risk/impact gates are attributed individually; one final human outcome validates all actual reviews and exact council references, never release permission.

  4. Resume without resetting evidence

    ResumeAsync retains the exact script and inner IDs. Pending/submit/poll/renew APIs authenticate original actors and evidence. ReconcileMemberAsync resolves an uncertain connector outcome without replay; ReconcileEvidenceAsync repairs only an exact interrupted hub append. Authenticated final changes select the real owner through ReviseMemberAsync and preserve original outputs and the two-cycle cap. Aggregate ReconcileConsumptionAsync calibrates a complete accepted run once without changing inner charges.

Watch, live remote setup, tenant/case isolation, business-quality evaluation, Linux/package-consumer proof and IndustryIQ integration remain separate work. Multi-repository federation is deferred upstream.

Use the confirmed lifecycle API

using var federation = await factory.CreateFederationAsync();
var initialized = await federation.InitializeAsync(
[
    new() { Name = "product", Description = "Requirements and product decisions",
        Patterns = ["requirements"], Roster = new() { Profile = "product" } },
    new() { Name = "platform", Description = "Independent architecture work",
        Patterns = ["architecture"], Roster = new() { Profile = "architecture" } },
]);
if (initialized.Status != SquadRunStatus.Completed)
    throw new InvalidOperationException(initialized.Diagnostic);
using var product = await federation.CreateMemberRuntimeAsync("product");
var research = await product.RunAsync("Research the authorized existing case.");

factory is the existing DI factory with a caller-owned client and an ApproveAsync that actually presents the full proposal. No model or connector permission comes from these configuration values. To promote instead, inspect GetPromotionCandidates(), pass the exact selected directory paths to PromoteAsync and respect any pending operation ID. An MCP server is not required.

Run a verified producer/consumer dependency

var outcome = await federation.RunAsync(
    "Produce the authorized product requirements, then their architecture plan.",
    new SquadFederationRunConfiguration
    {
        Members = ["product", "platform"],
        Requests = new Dictionary<string, string>
        {
            ["product"] = "Produce the authorized product requirements.",
            ["platform"] = "Produce an architecture outcome from the supplied requirements.",
        },
        Dependencies = [new("product", "platform", "lead", Stage: "plan")],
    });
if (outcome.Status != SquadRunStatus.Completed)
    throw new InvalidOperationException(outcome.Diagnostic);

This uses the producer's current actual lead-plan artifact, not a guessed path. Choose the real role/stage for your registered outcome. Mode is a trusted host option, not request prose. Target = "platform" instead forwards one inner run without a meta-pipeline. A suspended result must use its exact meta-run ID; do not replace it with another request.

Watch is a trigger, not another autonomy mode

HandleWatchEventAsync(event, configuration) authenticates the explicit repository signal before any state or model work. Label opt-ins require the actual write collaborator; commands require an authorized human; schedules, manual dispatches and filtered pushes require the exact reviewed committed workflow. Forks and unmatched/unauthorized events are explicitly ignored. Provider authentication and terminal action permission are separate. Unlike interactive lifecycle confirmation, this narrowly authorized trigger may bootstrap only its own in-repository native state; it waives no inner human gate.

Opted-in eventActual intent and terminal surface
Issue carrying squad/autoOrdinary autopilot; host-prepared branch and verified draft PR
Same-repository PR carrying squad/reviewIndependent intake and focused tester review; COMMENT-only review
Authorized /squad commentRouted installed owner; corresponding draft/comment/issue
Committed schedule/manual dispatchTrusted host-selected task/mode; draft or issue
Committed filtered pushActual research/plan and independent validation council; verdict comment

Names use only numbers, workflow IDs, UTC dates and normalized branch/commit metadata. Fresh Init, quiescent native-v2 Promotion, additive Expansion and matching native orphan re-registration preserve original evidence. Human-created or unproven trees are never overwritten. Only an unstarted exact seed image may repair a missing tree; restore lost started authority instead of replaying work or inventing spend. Event trees are retained. Control-plane entry uses the existing exclusive native execution lock; no federation-level meta-pipeline is started.

Original event input is byte-bound read-only case data. Text cannot change roots, model policy, modes, tiers, ceiling or permissions. Control assignments are recorded as ignored; they do not become task-fit cues. No unattended discovery or Scribe overlap is enabled. Independent intake still runs. An absent intake/council seat blocks with the role to add separately; Watch never adds or waives it. Mandatory risk, cost and impactful-action gates remain unchanged.

var watch = new SquadWatchConfiguration
{
    Repository = "owner/repository",
    Authority = authenticatedEventAuthority,
    TerminalConnector = independentlyAuthorizedTerminal,
};
federation.RegisterWatch(watch);
var result = await federation.HandleWatchEventAsync(platformEvent, watch);
if (result.Status == SquadWatchStatus.ReconciliationRequired)
    await federation.ReconcileWatchAsync(result.Trigger!.WatchRunId, watch);

The two integrations and event are supplied by the trusted host. RegisterWatch restores the same policy after restart for pending/read/submit/poll/renew. Prepared has no fabricated URL; Delivered requires an actual provider postcondition and is not human acceptance or release permission. A pending risk gate may have a verified draft/escalation while still blocking work. Reconciliation never implicitly resumes or retries an uncertain operation.

The native --watch-event runner takes a separate --watch-settings file and durable isolated case root. Configure the reviewed workflow Git blob SHA, actual model, registered approver and host-owned credentials. The GitHub draft connector only verifies an already prepared non-protected squad-watch/ branch and exact published output bytes; it cannot push, merge or deploy. The workflow reference is not installed automatically, assumes no Copilot CLI and requires explicit durable storage/host setup. Do not publish protected input, state or credentials in CI. Live remote permissions, IndustryIQ authorization/business quality, Linux and package-consumer evidence remain separate.

Read a member without granting cross-case disclosure

federation.CreateReports(configuration) uses the state-read-only document/governance APIs. A Squad selector confines reads to the exact member, even when a sibling or hub needs repair; it grants no shared-document search permission. Omission aggregates only after explicit host authorization for every case. Actual current roster cells and sealed relocated histories remain authoritative. The helpers do not repair, initialize, resume or replay work.

Original Watch inputs, lifecycle images, human/effect payloads, sessions and raw actor/contact values are not report fields. Trigger authorization is not export or learning consent. Original inner dispatch/provider evidence supplies metrics once; native bootstrap, terminal publication, meta-routing and handoffs cannot become fictitious role stages or a second consumption ledger. A real provider issue is counted only through its original delivery/effect observation, not its drafted URL. A local report is not human acceptance or release permission.

Keep member memory and learning isolated

federation.CreateMemory(configuration, "product") and CreateLearning(configuration, "product") bind one explicit portable member name. They read no hub or sibling memory, perform no aggregate discovery and do not reach global IDE memory. Each needs its own host case/role or actual-human/source rights; Watch trigger authorization is neither memory disclosure nor outward learning consent. The native memory/learning reference describes the exact APIs, sanitization, SL/TL rows, prepared-only commands and individually authenticated provider actions.

Confirmed native-v2 promotion copies original role-memory bytes and preserves their immutable Scribe receipts through sealed historical mappings. The new member's root becomes the current location, not authority to rewrite old memory. A started/unverified learning mutation prevents federation promotion until its original provider effect is reconciled; moving active authority is not a workaround. Scribe memory/learning and provider actions add no fake model role stages or second hub consumption ledger. Final source-repository PR review remains separate from inner or aggregate human acceptance.
