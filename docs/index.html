Why HVE Squad inside MAF?

Bring the method into the application.

MAF supplies the agent execution primitives. This integration adds the released HVE Squad methodology, roster resolution, approval gates, and evidence-backed state around those primitives.

A clear boundary is a feature.

Interactive. Single squad. One producing-role owner per turn.

This preview does not implement federation, Watch Mode, autonomous/autopilot loops, discovery interviews, or multi-owner fan-out. Native child dispatch is real delegation, but it is not federation.

Why this scope was chosen, and what federation would require →

No bundled search, shell, test runner, deployment executor, or PowerPoint renderer is implied by a role's presence. Real-world effects require your actual registered host functions and successful evidence. Completed does not mean deployed or independently host-validated.

From documentation to a running host

Start small. Make every capability explicit.

Inspect the release without model credentials. Bind an existing IChatClient. Run a focused request. Add effectful tools only when their approval and evidence contracts are ready.
