Why HVE Squad inside MAF?

Bring the method into the application.

This is a .NET library intended for NuGet consumption inside your AI application, not a Copilot plugin or a tool for developing the application itself. MAF supplies agent execution; this integration adds released roles, an approved plan, a single producing owner, review, and evidence-backed state. The preview is available from source or a local feed; see how maintainers publish the package.

01 / METHOD

Give a draft an accountable owner

Use existing HVE research, planning, writing, and review specialists. Ground their work in your approved material; the package does not ship custom sales or other domain-expert agents.

See the role-to-work mapping →
02 / CONTROL

Keep the application in charge

Your app owns identity, document rights, case isolation, the model provider, and the approval UI. A drafted recommendation cannot authorize a price, change a customer record, or send itself.

Understand application responsibilities →
03 / ACCOUNTABILITY

Return evidence, not just an answer

Expose the draft alongside research, plan, review, and an explicit run status. The deterministic Scribe records actual dispatches and hashes; those receipts are not proof that every business claim is correct.

A clear boundary is a feature.

Interactive. Single squad. One producing-role owner per turn.

These are advisory document workflows using HVE specialists, not turnkey domain products. Input intake uses the released PRD Quality Reviewer and may block non-PRD material; assess that fit before offering an application feature.

This preview does not implement federation, Watch Mode, autonomous/autopilot loops, discovery interviews, or multi-owner fan-out. Native child dispatch is real delegation, but it is not federation.

Why this scope was chosen, and what federation would require →

The host supplies document ingestion, retrieval, approval transport, and secure output delivery. Native Markdown and evidence are not a Word/PDF service, pricing engine, or compliance proof. Completed does not mean externally sent or independently validated. For commodity ticket routing or simple summarization, plain MAF is often enough.
